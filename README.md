# RAG_Alfa_x_MIPT
Репозиторий с решением тестового задания в магистратуру Альфа-банка х МФТИ

## Подход

Корпус (1937 документов с сайта Альфа-Банка) разбивается на чанки по 150 слов с перекрытием 30 слов. Каждый чанк лемматизируется через pymorphy3.

Retrieval - гибридный, четыре сигнала с весами:
- BM25 (0.30) на леммах
- TF-IDF word bigrams (0.15) на леммах  
- TF-IDF char n-grams 3–5 (0.10) на леммах
- Векторный поиск FAISS IndexFlatIP (0.45) - эмбеддинги FRIDA (`ai-forever/FRIDA`, #1 ruMTEB)

Финальный скор - взвешенная сумма нормализованных сигналов. Из топ-K чанков берётся не более одного на документ (дедупликация по `doc_id`).

Генерация - `google/gemma-4-31b` через самостоятельный vllm-сервинг (1× A100 80 GB, кластер HSE сHARIZMA).

Если релевантных чанков не найдено, модель получает отдельный промпт с предложением обратиться в поддержку.

Разворачивать какую-либо LLM локально на ноутбуке по техническим причинам (MacBook Air) я не мог, тем более, что по условиям состязания модель является общедоступной на `huggingface`, никакие проприетарные API не используются.
Местонахождение стенда с видеокартами в нашей лаборатории в НИУ ВШЭ соответствует критерию локальности запуска :)
